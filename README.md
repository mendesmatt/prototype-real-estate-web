# Real Estate — High-end Property Website

> Interactive real estate web app prototype, featuring a property showcase and lead capture for a high-end regional market.

`HTML5` · `CSS3` · `JavaScript`

## 🇬🇧 English

**Segment:** Real estate & property brokerage

Interactive real estate web app prototype, featuring a property showcase and lead capture for a high-end regional market.

**Highlights**

- Gated-community showcase by region and road marker
- Filterable listings of high-end properties
- Specialist contact and lead capture form

**Tech:** HTML5, CSS3, vanilla JavaScript.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
